# Glossary
• Action Instances are instances of an Action Blueprint that are added to your Dispatch Plan.
• Dispatch Plans are the entities in which Action Instances are created. Dispatch Plans are linked to a Holding Bay. Inside of the Dispatch Plans we can create, edit, delete, and re-order Action Instances.
• Holding Bay is the entity used for the transmission. Action Instances can be referenced here from a Dispatch Plan. The transmission unit will retrieve the Action Instances from the Holding Bay before proceeding with the transmission.
• Action Serializer converts the Action Instance's data (including metadata and arguments) into binary.
Holding Bays
The new paradigm in the Action Dispatch System is based on the Holding Bays. As mentioned before, the Holding Bay is an entity on which we rely for the Action Instances transmission.
